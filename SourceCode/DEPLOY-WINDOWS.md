# ติดตั้ง IT Helpdesk บน Windows

> **สถานะการทดสอบ (อ่านก่อน):** โค้ดระบบและตัวอ่าน `.env` ผ่านการทดสอบอัตโนมัติ 58 รายการ แต่สคริปต์ติดตั้ง Windows (`deploy\windows\*.ps1`, `*.bat`) **เขียนโดยไม่ได้รันบน Windows จริง** (เครื่องที่ใช้พัฒนาเป็น Linux) จึงควรลองบนเครื่องทดสอบก่อนใช้งานจริง ถ้าติดขัดตรงไหนให้ส่งข้อความผิดพลาดมา จะแก้ให้

## สิ่งที่ต้องมี
- Windows 10/11 หรือ Windows Server 2016 ขึ้นไป
- **Node.js 22.13 ขึ้นไป** (โหลดตัว LTS จาก https://nodejs.org ติดตั้งแบบปกติ ติ๊ก "Add to PATH")
- ไม่ต้องติดตั้งอะไรเพิ่ม ไม่ต้อง `npm install` ไม่ต้องมีฐานข้อมูลแยก (ใช้ SQLite ในตัว)

## ลองใช้ก่อน (1 นาที)
1. แตกไฟล์ zip ไปที่ เช่น `C:\helpdesk`
2. ดับเบิลคลิก `deploy\windows\start-here.bat`
3. เปิดเบราว์เซอร์ที่ http://localhost:3000
4. รหัสผ่าน `admin` ครั้งแรกจะแสดงในหน้าต่างดำ (บรรทัด `[setup]`) **แสดงครั้งเดียว** จดไว้ แล้วเข้าสู่ระบบและเปลี่ยนรหัสผ่าน
5. ปิดหน้าต่างเพื่อหยุดระบบ

## ติดตั้งให้ทำงานถาวร (เปิดเครื่องแล้วรันเอง)
1. กดปุ่ม Start พิมพ์ `PowerShell` คลิกขวา → **Run as administrator**
2. ไปที่โฟลเดอร์ระบบแล้วรัน
   ```powershell
   cd C:\helpdesk
   powershell -ExecutionPolicy Bypass -File deploy\windows\install.ps1 -OpenFirewall
   ```
   - `-OpenFirewall` เปิดพอร์ตให้เครื่องอื่นในออฟฟิศเข้าได้ (เฉพาะเครือข่าย Domain/Private) ไม่ใส่ถ้าใช้เครื่องเดียว
   - `-BackupTime 23:30` เปลี่ยนเวลาสำรองข้อมูล (ค่าเริ่มต้น 02:00)
3. สคริปต์จะ: สร้างไฟล์ `.env` จาก `.env.windows.example`, สร้างงานอัตโนมัติ 2 งานใน Task Scheduler
   - `IT-Helpdesk` — เริ่มตอนเปิดเครื่อง (ไม่ต้องล็อกอิน) และเริ่มใหม่เองถ้าล่ม
   - `IT-Helpdesk-Backup` — สำรองฐานข้อมูลทุกวัน แล้วเริ่มระบบทันที
4. รหัสผ่าน `admin` ครั้งแรก: เปิด `logs\helpdesk.log` ค้นหา `[setup]`

เครื่องอื่นในออฟฟิศเปิดที่ `http://ชื่อเครื่องหรือIP:3000`

## การใช้งานประจำ
| งาน | วิธี |
|---|---|
| ดู log | `Get-Content C:\helpdesk\logs\helpdesk.log -Tail 50` |
| หยุด / เริ่ม | Task Scheduler → `IT-Helpdesk` คลิกขวา End / Run หรือ `Stop-ScheduledTask IT-Helpdesk` |
| แก้ตั้งค่า | แก้ `.env` ด้วย Notepad แล้วสั่ง End → Run งาน `IT-Helpdesk` |
| สำรองทันที | `node scripts\backup.js` (ไฟล์อยู่ที่ `data\backups\`) |
| ลืมรหัส admin | `node scripts\reset-password.js admin` (พิมพ์รหัสใหม่ให้) |
| กู้คืนข้อมูล | หยุดระบบก่อน แล้ว `node scripts\restore.js data\backups\helpdesk-xxxx.db.gz` |
| อัปเกรด | หยุดระบบ → แทนที่ไฟล์โปรแกรมด้วยเวอร์ชันใหม่ **ยกเว้นโฟลเดอร์ `data` และไฟล์ `.env`** → เริ่มระบบ |
| ถอนการติดตั้ง | `powershell -ExecutionPolicy Bypass -File deploy\windows\uninstall.ps1` (ข้อมูลไม่ถูกลบ) |

ข้อมูลทั้งหมดอยู่ที่โฟลเดอร์ `data\` (ฐานข้อมูล, กุญแจล็อกอิน, รูปแนบ) ถ้าต้องการย้ายไปไดรฟ์อื่น ตั้ง `DATA_DIR=D:\helpdesk-data` ใน `.env`

## ข้อควรระวังด้านความปลอดภัย
- **ไฟล์สำรองอยู่เครื่องเดียวกับระบบ** ถ้าฮาร์ดดิสก์เสียจะหายหมด ให้คัดลอกโฟลเดอร์ `data\backups` ไปเก็บที่อื่นเป็นประจำ (ไดรฟ์ภายนอก/เครือข่าย)
- ใช้ภายในออฟฟิศผ่าน `http://` ได้ แต่รหัสผ่านจะวิ่งบนเครือข่ายแบบไม่เข้ารหัส ถ้าเปิดออกอินเทอร์เน็ตหรือมีหน้าแจ้งซ่อมสำหรับคนนอก **ต้องใช้ HTTPS**
- อย่าเปิดพอร์ตออกอินเทอร์เน็ตตรง ๆ ผ่านเราเตอร์โดยไม่มี HTTPS

## เปิดใช้ HTTPS บน Windows (ทางเลือก)
วิธีที่ง่ายที่สุดคือใช้ [Caddy](https://caddyserver.com/download) (ไฟล์เดียว `caddy.exe`, ขอใบรับรองฟรีให้เอง ต้องมีชื่อโดเมนที่ชี้มาที่เครื่องนี้และเปิดพอร์ต 80/443):
1. ใน `.env` เอา `#` หน้า `HOST=127.0.0.1` และ `TRUST_PROXY=1` ออก แล้วรีสตาร์ทงาน `IT-Helpdesk`
2. สร้างไฟล์ `Caddyfile` (ข้างๆ `caddy.exe`):
   ```
   helpdesk.mycompany.co.th {
       request_body { max_size 8MB }
       reverse_proxy 127.0.0.1:3000 {
           flush_interval -1
       }
   }
   ```
3. ทดสอบด้วย `caddy run` ถ้าใช้ได้ ค่อยตั้งให้รันถาวร (`caddy.exe` ไม่มีตัวติดตั้งเป็นบริการในตัว ใช้ Task Scheduler แบบเดียวกับ `IT-Helpdesk` หรือเครื่องมืออย่าง NSSM)

`flush_interval -1` จำเป็น ไม่เช่นนั้นการอัปเดตสถานะแบบเรียลไทม์จะค้าง

## แก้ปัญหาเบื้องต้น
- **`ไม่พบ Node.js`** — ติดตั้ง Node.js แล้วปิด/เปิด PowerShell ใหม่ ตรวจด้วย `node -v`
- **เปิดเว็บไม่ได้จากเครื่องอื่น** — ตรวจว่าใช้ `-OpenFirewall` หรือเปิดไฟร์วอลล์พอร์ต 3000 แล้ว และ `HOST` ใน `.env` ไม่ได้ตั้งเป็น `127.0.0.1`
- **พอร์ตถูกใช้อยู่** — เปลี่ยน `PORT=` ใน `.env` แล้วรัน `install.ps1` ใหม่ (เพื่ออัปเดตกฎไฟร์วอลล์)
- **งานไม่ทำงานหลังรีบูต** — Task Scheduler → `IT-Helpdesk` → ดู Last Run Result และดู `logs\helpdesk.log` บรรทัด `stopped, exit code`
- **ย้ายโฟลเดอร์โปรแกรม** — รัน `uninstall.ps1` ที่เดิม แล้วรัน `install.ps1` ที่โฟลเดอร์ใหม่
