# Mini Project – ระบบแจ้งซ่อมและติดตามสถานะอุปกรณ์ไอที (IT Helpdesk System)

**ผู้จัดทำ:** [นายวรรณวุฒิ สุขมาก] รหัสนักศึกษา [68111933]
**วิชา:** [CE306 โปรแกรมประยุกต์บนเว็บ]  

ระบบแจ้งซ่อมแบบตั๋ว (Ticket) สำหรับองค์กร มี 3 บทบาท (พนักงาน / ช่างไอที / ผู้จัดการ) ติดตามสถานะแบบเรียลไทม์ มี REST API, JWT, สถิติ KPI และหน้าแจ้งซ่อมสำหรับผู้ที่ไม่มีบัญชี

| `Evidence/` | ภาพหลักฐานผลการทำงานของระบบ |

## สิ่งที่ต้องมี

- ไม่ต้องติดตั้งแพ็กเกจเพิ่ม (ไม่ต้อง `npm install`) และไม่ต้องติดตั้งฐานข้อมูล (ใช้ SQLite ในตัว Node.js)

ตรวจเวอร์ชันด้วย `node -v`

## วิธีติดตั้งและเปิดใช้งาน

### Windows
1. แตกไฟล์ zip แล้วเปิดโฟลเดอร์ `02_SourceCode`
2. ดับเบิลคลิก `deploy\windows\start-here.bat`
3. เปิดเบราว์เซอร์ที่ http://localhost:3000
4. รหัสผ่านผู้ดูแลระบบ (`admin`) ครั้งแรกจะแสดงในหน้าต่างดำที่บรรทัด `[setup]` **แสดงครั้งเดียว ให้จดไว้**
5. ปิดหน้าต่างดำเพื่อหยุดระบบ

หรือเปิดโฟลเดอร์ `SourceCode` ใน VS Code แล้วรันในเทอร์มินัล: `npm start`

### macOS / Linux
```bash
cd SourceCode
npm start          # เปิดที่ http://localhost:3000
```

## วิธีใช้งาน

**พนักงาน** – ล็อกอิน → กรอกหัวข้อ หมวดหมู่ ความเร่งด่วน และอาการ (แนบรูปได้ไม่เกิน 3 รูป) → กด "ส่งเรื่องแจ้งซ่อม" → ดูแถบสถานะ (รอรับเรื่อง → กำลังดำเนินการ → เสร็จสิ้น) ที่อัปเดตเองโดยไม่ต้องรีเฟรช

**ช่างไอที** – เห็นตั๋วทั้งหมด → กด "รับงานนี้" → "เริ่มดำเนินการ" → "แก้ไขเสร็จสิ้น" พร้อมบันทึกการซ่อม และปุ่ม "+ เพิ่มโน้ต" (ระบบบันทึกชื่อผู้ทำและเวลาให้อัตโนมัติ)

**ผู้จัดการ / ผู้ดูแลระบบ (`admin`)** – ดูภาพรวมและ KPI (เวลาตอบรับเฉลี่ย เวลาแก้ไขเฉลี่ย ผลงานช่างรายคน) → มอบหมายงานให้ช่าง → เมนู "จัดการผู้ใช้": เพิ่มพนักงาน/ช่าง แก้ชื่อ เปลี่ยนบทบาท รีเซ็ตรหัสผ่าน ปิดการใช้งานบัญชี

**ผู้ที่ไม่มีบัญชี** – เปิด `/report.html` → กรอกชื่อ ช่องทางติดต่อ และอาการ → ได้ลิงก์ติดตามส่วนตัว (เก็บไว้ให้ดี) เปิดดูสถานะได้ที่ `/track.html`
